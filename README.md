# VEATION beta

Downloads for the closed beta of VEATION, the immersive video editor by Alma Digital Studio (fulldome, 2D and 360 room).

- The installers are on the [Releases](https://github.com/beltranlihn/veation-beta/releases) page.
- VEATION needs a personal licence key. Each tester receives one by email. A key works on one computer only.
- Each release also carries the complete source code of the third-party components that VEATION distributes under the
  GNU GPL and the GNU LGPL (FFmpeg and the plug-ins of the Windows installer). The licence notices installed with VEATION
  (`resources/licenses/THIRD-PARTY-NOTICES.txt`) link to these files.

This repository does not contain the source code of VEATION.

www.veation.com
